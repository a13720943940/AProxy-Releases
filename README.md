# AProxy Releases

AProxy 是支持浏览器内代理、订阅节点、书签、历史记录和全屏浏览的 iOS 浏览器，最低 iOS 18。

## 下载与安装

[最新未签名 IPA](https://github.com/a13720943940/AProxy-Releases/releases/latest)

下载 IPA 后导入全能签等签名工具签名安装。已有用户请使用相同 Bundle ID 与签名身份覆盖安装，避免卸载丢失本地数据。

从 1.3.0 起，可在「代理与浏览器设置 → 检查更新」查看新版、下载并校验安装包，再共享给签名工具。

每个 Release 包含 IPA 与 update.json（版本号、Build、说明、下载地址和 SHA-256）。本仓库不存放源码、代理订阅、凭据或签名证书。

更新检查默认每天最多一次，可在应用更新页面关闭。更新下载依赖设备能够访问 GitHub。
